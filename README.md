# VK + Yandex RAG Bot: Репетитор по ЧПУ с системой метрик

Интеллектуальный бот-ассистент для ВКонтакте, разработанный на базе технологий RAG (Retrieval-Augmented Generation). Бот выступает в роли репетитора по программированию станков с ЧПУ Fanuc для учебного центра «Точка отсчета».

## 🚀 Ключевые особенности
- **RAG-архитектура:** Поиск ответов осуществляется по локальной базе знаний (документы .docx, .txt), что исключает «галлюцинации» нейросети.
- **Модели YandexGPT:** Использование `yandexgpt-5-lite` для генерации ответов и текстовых эмбеддингов для векторного поиска.
- **Система логирования и метрик:** Автоматический сбор статистики взаимодействий (время ответа, статус запроса, ID пользователя) в базу данных SQLite (`logs.db`).
- **Контекстная память:** Бот помнит историю диалога, что позволяет вести естественную беседу.

## 🛠 Технологический стек
- **Язык:** Python 3.10+
- **API:** VK API, Yandex AI Cloud
- **Векторная база:** FAISS (Facebook AI Similarity Search)
- **Логирование:** SQLite3, стандартный модуль logging
- **Управление зависимостями:** uv / pip

## 💬 Доступные команды
- `/start` — запуск бота и приветственное сообщение.
- `/help` — справка по возможностям ассистента.
- `/ingest` — переиндексация базы знаний (читает файлы `.txt`, `.doc`, `.docx` из папки `data/docs`).
- `/stats` — вывод статистики работы RAG-системы и метрик производительности (время ответа, количество запросов).
- `/clear` — очистка истории текущего диалога.

## 📊 Метрики и Логирование
Проект включает встроенный класс `DatabaseLogger`, который фиксирует:
1. **Время обработки запроса:** Позволяет отслеживать производительность системы в реальном времени.
2. **Источники ответов:** Анализ того, какие документы из базы знаний используются чаще всего.
3. **Статус выполнения:** Успешные ответы и системные ошибки для быстрой отладки.

Для просмотра актуальной статистики используйте команду `/stats` в диалоге с ботом.

## ⚙️ Установка и запуск

### Требования
- Установленный Python и утилита `uv` (или `pip`).
- Аккаунт разработчика ВКонтакте и доступ к Yandex AI Cloud.

### Шаги запуска
1. Клонируйте репозиторий:
   ```bash
   git clone [ссылка_на_ваш_репозиторий]
   cd bot_vk_yandex

2 Настройте переменные окружения. Скопируйте .env.example в .env и заполните ключи:
VK_GROUP_ID и VK_ACCESS_TOKEN
YANDEX_API_KEY и YANDEX_FOLDER_ID

3. Запустите бота через автоматизированный скрипт:
   ./start_bot.bat

Скрипт автоматически создаст виртуальное окружение, установит зависимости и запустит процесс.

📁 Структура проекта
bot.py — основная логика бота и интеграция с VK API.
db_logger.py — модуль для записи метрик в SQLite.
rag/ — папка с логикой векторного поиска и работы с LLM.
data/docs/ — папка с учебными материалами по ЧПУ.
logs.db — файл базы данных с историей взаимодействий.
